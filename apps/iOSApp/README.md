# iOSApp

iOS companion app built with SwiftUI + WidgetKit extension.

This directory will contain the Xcode project. Create it with:
Xcode > File > New > Project > iOS App > "LLMUsageMonitor-iOS"

The app depends on the `UsageCore` package at the repo root.
It is read-only — all usage data arrives via CloudKit sync from the Mac app.
